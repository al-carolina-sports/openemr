# ICD-10-CM reference for the specificity checks.
#
# Format:  CODE | description | flags
# Flags (comma separated, all optional):
#   unspecified     - the code itself means "unspecified"; more specific siblings exist
#   side=right      - the code encodes a right-sided diagnosis
#   side=left       - left-sided
#   side=bilateral  - bilateral
#   side=none       - the code's family does not encode a side at all
#   category        - 3-character category, not billable on a claim
#
# This file is a working reference for the codes this library actually uses, not
# a full ICD-10-CM distribution. Add the codes you transcribe. An unknown code is
# checked for FORMAT only and reported as unverified, never as wrong.
